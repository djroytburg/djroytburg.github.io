# Website CV

Run `make` from this directory to rebuild `../pdfs/cv.pdf`.

The current two-page layout is generated by `render-cv.py` from `cv.json`,
`../roytburg.bib`, and `../publications_meta.json`. It uses XeLaTeX with
TeX Gyre fonts shipped with TeX Live. Publication links and equal-contribution
markers share the website metadata. `cv.tex` is generated; edit the data or
renderer instead. The static-site builder copies the result to `docs/pdfs/`.

The older `make-tex.py` and `cv-header.tex` remain as the legacy template.
